# 100 Shio use cases

60 business processes and 40 workflows that chain them, each a runnable `.shio` program with 372 cases between them. In every one the model reads, and code decides against something the model cannot talk its way past: a record, a policy table, arithmetic, a checksum, a date, or a quote that must appear in a text that code chose. Every program has a clean case and failures of different kinds: the model misreads, invents, or is manipulated, or the input is simply bad. Shio does not stop a model from being fooled; it stops a fooled model's output from deciding.

```bash
python3 examples/usecases/run_all.py                # every program, offline, with scripted model answers
python3 examples/usecases/run_all.py --show refund  # and what each case decided
SHIO_MODEL=qwen3:8b python3 examples/usecases/run_all.py refund   # the same program on a real model (Ollama)
```

Writing one: [AUTHORING.md](AUTHORING.md). This page is generated by `catalog.py` from the programs' own runs.
